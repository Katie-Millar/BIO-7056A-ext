6.3 Type I and Type II Errors

These are the two types of errors can occur when we are testing hypotheses, and they are related to the null hypothesis. We were first introduced to the idea of the null hypothesis in Workshop 4. The null hypothesis is a statement that there is between the variables being tested.

6.3.1 Type I Error

If we reject the null hypothesis when it is actually true, we have made a Type I error.

6.3.2 Type II Error

If we fail to reject the null hypothesis when it is actually false, we have made a Type II error.

6.4 Transforming Data

So far in this module, we have practised a range of statistical tests, including t-tests and ANOVAs. Before running these tests, we always check two key assumptions:

  1. Normality: the data within each group should be approximately normally distributed (checked using the Shapiro-Wilk test and Q-Q plots)

  2. Homogeneity of variance: the variance within each group should be approximately equal (checked using Levene’s test)

When both assumptions are met, we can proceed with a parametric test. When they are not met, we have two options:

  • Use a non-parametric alternative (covered in Workshop 3)
  • Transform the data to see whether the assumptions can be satisfied on a different scale

This section focuses on the second option — data transformation.

Note

What is a transformation?

A transformation applies a mathematical function to every value in a variable. This changes the scale of the data but not the relationships within it — the same otters that had higher tick counts before transformation will still have relatively high counts after transformation. The goal is to make the distribution more symmetrical and closer to normal.

6.4.1 Common Transformations

Transformation R code When to use
Log log(x) or log10(x) Right-skewed data, counts, data spanning several orders of magnitude
Square root sqrt(x) Count data with moderate right skew
Reciprocal 1/x Extreme right skew

The most commonly used transformation in biology is the log transformation, which is particularly useful for count data such as tick counts or parasite counts, as seen in Workshop 2 and this workshop.

What is written in the table may seem a bit daunting at first — the dropdown below explains each transformation in more detail.

6.4.2 Log Transformation

A log transformation is used when your data are right skewed. As you may remember from the histograms in Workshop 2, right-skewed data have a long tail stretching to the right — most values are clustered at the low end, but a small number of very high values pull the tail outward.

Log transformation works best when the data are:

  • Right skewed — as described above
  • Counts or measurements that cannot be negative — log transformation only works on positive values. Examples from our workshops include:
    • parasite_count from the wood mouse dataset — the number of parasites found on each mouse (discrete)
    • tick_count from the otter dataset — the number of ticks recorded on each otter (discrete)
    • fish_index from the otter dataset — a continuous measure of fish availability (continuous)
  • Spanning a wide range of values — for example, values ranging from 1 to 1,000, where the high values are distorting the distribution

6.4.3 Square Root Transformation

A square root transformation is a milder version of the log transformation. It is useful when the data are moderately right-skewed but the skew is not as extreme.

If the log transformation overcorrects and makes the data left-skewed, try the square root transformation instead.

It works best for:

  • Count data with moderate skew
  • Data where zeros are present

6.4.4 Reciprocal Transformation

The reciprocal transformation (1/x) is the strongest of the three and is used only when the data are extremely right skewed — for example, reaction times or waiting times, where a few very large values dominate the distribution.

Warning

The reciprocal transformation reverses the order of the data — a large value becomes a small value and vice versa. This means results must be interpreted carefully. It also cannot be applied when any values are zero.

Warning

Important: log(0) is undefined in mathematics. If your data contain zeros (which count data often does), always use log(x + 1) instead. This shifts all values up by 1 before taking the log, avoiding the problem.

6.4.5 The Workflow

The key principle is to check, transform, then check again:

  • Check normality of the original data (Shapiro-Wilk)
  • If assumptions are violated, apply a transformation
  • Check normality of the transformed data (Shapiro-Wilk)
  • If assumptions are now met, proceed with parametric test on transformed data
  • If assumptions are still violated, consider a non-parametric test instead

6.4.6 Step 1: Check the Original Data

We will use the tick_count variable from the otter dataset — the number of ticks recorded on each otter during the survey. Like many count variables in biology, we might expect this to be right-skewed.

ggplot(otter_data, aes(x = tick_count)) +
  geom_histogram(binwidth = 1, fill = "lightblue", colour = "black") +
  labs(x = "Tick count", y = "Frequency",
       title = "Before: raw tick counts") +
  theme_minimal(base_size = 13)
# Formally test normality
shapiro.test(otter_data$tick_count)

W = 0.83418, p-value = 1.072e-06

What does the histogram tell us about the distribution of tick counts?

6.4.7 Step 2: Apply the Log Transformation

otter_data <- otter_data %>%
  mutate(log_tick_count = log(tick_count + 1))
# We use log(x + 1) because some otters have a tick count of 0
# and log(0) is undefined
Note

Why are we using log(x + 1) and not just log(x)?

Some otters in this dataset have a tick count of 0, they had no ticks recorded during the survey. log(0) is undefined and R will return -Inf. Adding 1 to every value before taking the log avoids this problem, while having a very small effect on the shape of the distribution.

6.4.9 Step 4: Decide Whether to Proceed

After transformation, we check the Shapiro-Wilk test again:

  • If p > 0.05: the transformed data are approximately normal; proceed with a parametric test using log_tick_count
  • If p < 0.05: the transformation has not resolved the issue; consider a non-parametric test instead

In our case, the Shapiro-Wilk test returns p = 0.112 after log transformation, the tick count data are now approximately normally distributed and we can proceed with a parametric test.

# Run a t-test on the log-transformed tick counts by sex
t.test(log_tick_count ~ sex, data = otter_data, var.equal = TRUE)

    Two Sample t-test

data:  log_tick_count by sex
t = 0.14374, df = 58, p-value = 0.8862
alternative hypothesis: true difference in means between group female and group male is not equal to 0
95 percent confidence interval:
 -0.3234387  0.3734845
sample estimates:
mean in group female   mean in group male 
            1.325001             1.299978
Note

Interpreting results on a transformed scale:

When you transform your data, your results are on the transformed scale. For example, the t-test above compares log(tick_count + 1) between male and female otters — the difference between groups is expressed in log units, not raw tick counts. This is worth mentioning when writing up your results.

If the Shapiro-Wilk test still returns p < 0.05 after log transformation, what should you do?

Warning

Transformation is not always the answer.

If the data are still non-normal after transformation, do not keep trying different transformations until one works. Instead, use a non-parametric test. Refer back to the parametric vs non-parametric table in Workshop 3.

6.4.11 Non-Parametric Alternatives

When transformation does not work, we can use a non-parametric test instead. Non-parametric tests do not assume that the data are normally distributed, and they are often based on ranks rather than raw values.

If you can remember from Chapter 3, the Mann-Whitney U test (also called the Wilcoxon rank-sum test) is a non-parametric alternative to the independent samples t-test, and the Kruskal-Wallis test is a non-parametric alternative to one-way ANOVA.

Common parametric tests and their non-parametric equivalents, (Field, A. (2024))
Parametric test Non-parametric equivalent
One-sample t-test Wilcoxon signed-rank test
Two-sample t-test (unpaired) Mann-Whitney U/Wilcoxon rank-sum test
Two-sample t-test (paired) Wilcoxon signed-rank test
Pearson correlation Spearman correlation
One-way analysis of variance Kruskal-Wallis test

### Non-Parametric Alternatives
When transformation does not work, we can use a **non-parametric test** instead. Non-parametric tests do not assume that the data are normally distributed, and they are often based on **ranks** rather than raw values.

If you can remember from [Chapter 3](03-ext.qmd), the Mann-Whitney U test (also called the Wilcoxon rank-sum test) is a non-parametric alternative to the independent samples t-test, and the Kruskal-Wallis test is a non-parametric alternative to one-way ANOVA.


| Parametric test | Non-parametric equivalent |
|---|---|
| One-sample t-test | Wilcoxon signed-rank test |
| Two-sample t-test (unpaired) | Mann-Whitney U/Wilcoxon rank-sum test |
| Two-sample t-test (paired) | Wilcoxon signed-rank test |
| Pearson correlation | Spearman correlation |
| One-way analysis of variance | Kruskal-Wallis test |
