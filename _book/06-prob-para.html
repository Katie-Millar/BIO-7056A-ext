6.3 Type I and Type II Errors

These are the two types of errors can occur when we are testing hypotheses, and they are related to the null hypothesis. We were first introduced to the idea of the null hypothesis in Workshop 4. The null hypothesis is a statement that there is between the variables being tested.

6.3.1 Type I Error

If we reject the null hypothesis when it is actually true, we have made a Type I error.

6.3.2 Type II Error

If we fail to reject the null hypothesis when it is actually false, we have made a Type II error.

6.4 Transforming Data

So far in this module, we have practised a range of statistical tests, including t-tests and ANOVAs. Before running these tests, we always check two key assumptions:

  1. Normality: the data within each group should be approximately normally distributed (checked using the Shapiro-Wilk test and Q-Q plots)

  2. Homogeneity of variance: the variance within each group should be approximately equal (checked using Levene’s test)

When both assumptions are met, we can proceed with a parametric test. When they are not met, we have two options:

  • Use a non-parametric alternative (covered in Workshop 3)
  • Transform the data to see whether the assumptions can be satisfied on a different scale

This section focuses on the second option — data transformation.

Note

What is a transformation?

A transformation applies a mathematical function to every value in a variable. This changes the scale of the data but not the relationships within it — the same otters that had higher tick counts before transformation will still have relatively high counts after transformation. The goal is to make the distribution more symmetrical and closer to normal.

6.4.1 Common Transformations

Transformation R code When to use
Log log(x) or log10(x) Right-skewed data, counts, data spanning several orders of magnitude
Square root sqrt(x) Count data with moderate right skew
Reciprocal 1/x Extreme right skew

The most commonly used transformation in biology is the log transformation, which is particularly useful for count data such as tick counts or parasite counts, as seen in Workshop 2 and this workshop.

What is written in the table may seem a bit daunting at first — the dropdown below explains each transformation in more detail.

6.4.2 Log Transformation

A log transformation is used when your data are right skewed. As you may remember from the histograms in Workshop 2, right-skewed data have a long tail stretching to the right — most values are clustered at the low end, but a small number of very high values pull the tail outward.

Log transformation works best when the data are:

  • Right skewed — as described above
  • Counts or measurements that cannot be negative — log transformation only works on positive values. Examples from our workshops include:
    • parasite_count from the wood mouse dataset — the number of parasites found on each mouse (discrete)
    • tick_count from the otter dataset — the number of ticks recorded on each otter (discrete)
    • fish_index from the otter dataset — a continuous measure of fish availability (continuous)
  • Spanning a wide range of values — for example, values ranging from 1 to 1,000, where the high values are distorting the distribution

6.4.3 Square Root Transformation

A square root transformation is a milder version of the log transformation. It is useful when the data are moderately right-skewed but the skew is not as extreme.

If the log transformation overcorrects and makes the data left-skewed, try the square root transformation instead.

It works best for:

  • Count data with moderate skew
  • Data where zeros are present

6.4.4 Reciprocal Transformation

The reciprocal transformation (1/x) is the strongest of the three and is used only when the data are extremely right skewed — for example, reaction times or waiting times, where a few very large values dominate the distribution.

Warning

The reciprocal transformation reverses the order of the data — a large value becomes a small value and vice versa. This means results must be interpreted carefully. It also cannot be applied when any values are zero.

Warning

Important: log(0) is undefined in mathematics. If your data contain zeros (which count data often does), always use log(x + 1) instead. This shifts all values up by 1 before taking the log, avoiding the problem.

6.4.5 The Workflow

The key principle is to check, transform, then check again:

  • Check normality of the original data (Shapiro-Wilk)
  • If assumptions are violated, apply a transformation
  • Check normality of the transformed data (Shapiro-Wilk)
  • If assumptions are now met, proceed with parametric test on transformed data
  • If assumptions are still violated, consider a non-parametric test instead

6.4.6 Step 1: Check the Original Data

We will use the tick_count variable from the otter dataset — the number of ticks recorded on each otter during the survey. Like many count variables in biology, we might expect this to be right-skewed.

ggplot(otter_data, aes(x = tick_count)) +
  geom_histogram(binwidth = 1, fill = "lightblue", colour = "black") +
  labs(x = "Tick count", y = "Frequency",
       title = "Before: raw tick counts") +
  theme_minimal(base_size = 13)
# Formally test normality
shapiro.test(otter_data$tick_count)

    Shapiro-Wilk normality test

data:  otter_data$tick_count
W = 0.83418, p-value = 1.072e-06

What does the histogram tell us about the distribution of tick counts?

6.4.7 Step 2: Apply the Log Transformation

otter_data <- otter_data %>%
  mutate(log_tick_count = log(tick_count + 1))
# We use log(x + 1) because some otters have a tick count of 0
# and log(0) is undefined
Note

Why are we using log(x + 1) and not just log(x)?

Some otters in this dataset have a tick count of 0, they had no ticks recorded during the survey. log(0) is undefined and R will return -Inf. Adding 1 to every value before taking the log avoids this problem, while having a very small effect on the shape of the distribution.

6.4.9 Step 4: Decide Whether to Proceed

After transformation, we check the Shapiro-Wilk test again:

  • If p > 0.05: the transformed data are approximately normal; proceed with a parametric test using log_tick_count
  • If p < 0.05: the transformation has not resolved the issue; consider a non-parametric test instead

In our case, the Shapiro-Wilk test returns p = 0.112 after log transformation, the tick count data are now approximately normally distributed and we can proceed with a parametric test.

# Run a t-test on the log-transformed tick counts by sex
t.test(log_tick_count ~ sex, data = otter_data, var.equal = TRUE)

    Two Sample t-test

data:  log_tick_count by sex
t = 0.14374, df = 58, p-value = 0.8862
alternative hypothesis: true difference in means between group female and group male is not equal to 0
95 percent confidence interval:
 -0.3234387  0.3734845
sample estimates:
mean in group female   mean in group male 
            1.325001             1.299978
Note

Interpreting results on a transformed scale:

When you transform your data, your results are on the transformed scale. For example, the t-test above compares log(tick_count + 1) between male and female otters — the difference between groups is expressed in log units, not raw tick counts. This is worth mentioning when writing up your results.

If the Shapiro-Wilk test still returns p < 0.05 after log transformation, what should you do?

Warning

Transformation is not always the answer.

If the data are still non-normal after transformation, do not keep trying different transformations until one works. Instead, use a non-parametric test. Refer back to the parametric vs non-parametric table in Workshop 3.

Even after log transformation, the parasite count data remain significantly non-normal (p < 0.05). This is because the large number of zeros creates a spike at the left end of the distribution that transformation cannot remove. In this case, a non-parametric test would be the appropriate choice.

This contrast between the tick count data (transformation successful) and the parasite count data (transformation unsuccessful) illustrates an important principle — log transformation works best when zeros are relatively rare.

6.4.11 Non-Parametric Alternatives

When transformation does not work, we can use a non-parametric test instead. Non-parametric tests do not assume that the data are normally distributed, and they make no assumptions about the distribution of the data at all. They do not work by predicting the likely values of population parameters from sample statistics.

If you remember from Workshop 3, we introduced the concept of non-parametric equivalents. The table below serves as a reminder:

Common parametric tests and their non-parametric equivalents (Field, A. (2024))
Parametric test Non-parametric equivalent
One-sample t-test Wilcoxon signed-rank test
Two-sample t-test (unpaired) Mann-Whitney U / Wilcoxon rank-sum test
Two-sample t-test (paired) Wilcoxon signed-rank test
Pearson correlation Spearman correlation
One-way ANOVA Kruskal-Wallis test
Randomised block two-way ANOVA Friedman’s test

As discussed in the Main Workbook, non-parametric tests achieve this in one of three ways:

6.4.11.1 Median Tests

Most parametric tests compare means: a t-test compares the mean of one group to the mean of another, an ANOVA compares the means of multiple groups, and linear regression asks whether the mean of one variable changes in relation to another. However, when the data are skewed, the mean is pulled in the direction of the skew and no longer represents where most of the data sit.

Rather than comparing means, median tests compare medians. Because the median is the middle value, it is far less affected by extreme values and skew. Use the tabs below to switch between the mean and median plots and see the difference:

  • Mean

6.4.11.2 Rank Tests

Rather than using the actual values, the data are sorted into order and each observation is assigned a rank. The test then examines whether one group tends to rank consistently higher than another. Because the test uses ranks rather than raw values, it is not affected by skew or extreme values, making it a good choice for data that violate the normality assumption.

When comparing two groups, we use the Wilcoxon rank-sum test (also called the Mann-Whitney U test), the rank-based equivalent of a two-sample t-test:

data:  spraints by site

Note

Understanding the test statistics:

  • The Mann-Whitney U test produces a W statistic: if large enough relative to a critical value, it indicates a significant difference between the two groups.
  • The Kruskal-Wallis test produces a chi-squared statistic (sometimes called H). The larger the value, the more evidence that at least one group has a different rank distribution from the others

In both cases, the p-value tells us whether the result is statistically significant (p < 0.05).

6.4.11.3 Patterns of Deviation

Rather than looking at the size of differences, these methods look at the direction of differences. For example, do otters with higher fish availability tend to also have higher spraint counts? We are not asking by how much, just whether the two variables tend to move together.

Non-parametric tests for association:

When we want to measure the strength of association between two variables, we use a correlation coefficient. The most common parametric version is Pearson’s r, which measures the strength and direction of a linear relationship between two continuous, normally distributed variables and ranges from -1 to 1.

When the data are not normally distributed, or have been collected as ranks, the non-parametric alternatives are Spearman’s and Kendall’s correlation coefficients. Both are based on ranking data, yield coefficients comparable to Pearson’s r, and a significant result (p < 0.05) indicates a significant association.

To remind ourselves about the parametric Pearson’s r: What does a Pearson’s r value of -0.85 tell us?

Note

Spearman’s (ρ) and Kendall’s (τ) correlation coefficients both range from -1 to 1, just like Pearson’s r:

  • 1 — a perfect positive rank association
  • 0 — no association between the ranks
  • -1 — a perfect negative rank association

Kendall’s τ is typically slightly smaller in value than Spearman’s ρ for the same data — this is normal and does not mean one is better than the other. Both lead to the same conclusion about statistical significance. In practice, Spearman’s is more commonly reported in biology, but either is acceptable.

6.4.12 The difficulties of non-parametric tests

Non-parametric tests might seem like an easy solution. If the assumptions are violated or transformation does not work, just switch to a non-parametric test right?! However, there are some important things to be aware of before doing this.

When two or more observations share the same value, they are said to be tied. Most non-parametric tests are based on ranking, and ties create a problem because two observations cannot occupy the same rank position. R handles this automatically by assigning the average rank to tied values, but it is worth knowing this happens.

If three mice all have a parasite count of 0 and would occupy ranks 1, 2 and 3, what rank does each receive when ties are handled by averaging?

6.4.12.1 When Should You Use a Non-Parametric Test?

Note

Use a non-parametric test when:

  • The data are not normally distributed, and does not meet the assumptions of a parametric test
  • The data cannot be transformed to meet the normality assumption
  • The data were collected as ranks or represent an index rather than a true measurement
  • The sample size is very small and you cannot reliably assess normality

Do not use a non-parametric test simply because it is easier or to avoid checking assumptions — always check assumptions first and only switch to a non-parametric test if they cannot be met.

  labs(x = "Tick count", y = "Frequency",
       title = "Before: raw tick counts") +

# Formally test normality
shapiro.test(otter_data$tick_count)
```

### Step 2: Apply the Log Transformation

```{r transform-apply}
otter_data <- otter_data %>%
  mutate(log_tick_count = log(tick_count + 1))
# We use log(x + 1) because some otters have a tick count of 0
# and log(0) is undefined
```

::: {.callout-note}
**Why are we using `log(x + 1)` and not just `log(x)`?**

Some otters in this dataset have a tick count of 0, they had no ticks recorded during the survey. `log(0)` is undefined and R will return `-Inf`. Adding 1 to every value before taking the log avoids this problem, while having a very small effect on the shape of the distribution.
:::


---

### Step 3: Check the Transformed Data

```{r transform-compare, fig.cap="Figure 2. Raw (left) vs log-transformed (right) tick counts. The transformation makes the distribution more symmetrical.", fig.width=10, fig.height=4}

### Step 4: Decide Whether to Proceed

After transformation, we check the Shapiro-Wilk test again:

- If **p > 0.05**: the transformed data are approximately normal; proceed with a parametric test using `log_tick_count`
- If **p < 0.05**: the transformation has not resolved the issue; consider a **non-parametric test** instead

In our case, the Shapiro-Wilk test returns **p = 0.112** after log transformation, the tick count data are now approximately normally distributed and we can proceed with a parametric test.

```{r transform-ttest}
# Run a t-test on the log-transformed tick counts by sex
t.test(log_tick_count ~ sex, data = otter_data, var.equal = TRUE)
```

::: {.callout-note}
**Interpreting results on a transformed scale:**

When you transform your data, your results are on the **transformed scale**. 
For example, the t-test above compares `log(tick_count + 1)` between male and 
female otters — the difference between groups is expressed in log units, not 
raw tick counts. This is worth mentioning when writing up your results.
:::

**If the Shapiro-Wilk test still returns p < 0.05 after log transformation, what should you do?**

`r longmcq(c(
"Try more transformations until p > 0.05.",
answer = "Use a non-parametric alternative such as the Mann-Whitney U test or Kruskal-Wallis test, which do not require normality.",
"Proceed with the parametric test anyway.",
"Remove all outliers and rerun the transformation."
))`

::: {.callout-warning}
**Transformation is not always the answer.**

If the data are still non-normal after transformation, do not keep trying different transformations until one works. Instead, use a non-parametric test. Refer back to the parametric vs non-parametric table in [Workshop 3](03-ext.qmd).
:::

### When Transformation Does Not Work

To illustrate that transformation does not always solve the problem, let us revisit the `parasite_count` variable from the wood mouse dataset in [Workshop 2](02-ext.qmd). This variable is also right-skewed, but has a much larger proportion of zeros — most mice had no parasites at all.

```{r transform-mice, fig.cap="Figure 3. Raw (left) vs log-transformed (right) parasite counts in wood mice. The large number of zeros means the transformation is less successful.", fig.width=10, fig.height=4}

Even after log transformation, the parasite count data remain significantly non-normal (p < 0.05). In this case, a **non-parametric test** would be the appropriate choice.

This contrast between the tick count data (transformation successful) and the parasite count data (transformation unsuccessful) illustrates an important principle — **log transformation works best when zeros are relatively rare**.
:::

### Non-Parametric Alternatives

When transformation does not work, we can use a **non-parametric test** instead. Non-parametric tests do not assume that the data are normally distributed, and they make no assumptions about the distribution of the data at all. They do not 
work by predicting the likely values of population parameters from sample 
statistics.

If you remember from [Workshop 3](03-ext.qmd), we introduced the concept of non-parametric equivalents. The table below serves as a reminder:

| Parametric test | Non-parametric equivalent |
|---|---|
| One-sample t-test | Wilcoxon signed-rank test |
| Two-sample t-test (unpaired) | Mann-Whitney U / Wilcoxon rank-sum test |
| Two-sample t-test (paired) | Wilcoxon signed-rank test |
| Pearson correlation | Spearman correlation |
| One-way ANOVA | Kruskal-Wallis test |
| Randomised block two-way ANOVA | Friedman's test |

: Common parametric tests and their non-parametric equivalents (Field, A. (2024)) {.striped .hover}

---

As discussed in the [Main Workbook](https://ellenbell.github.io/7056Aworkshop-6---issues-with-probability-and-parametric-analysis.html), non-parametric tests achieve this in one of three ways:


#### Median Tests

Most parametric tests compare **means**: a t-test compares the mean of one group to the mean of another, an ANOVA compares the means of multiple groups, and linear regression asks whether the mean of one variable changes in relation to another. However, when the data are skewed, the mean is pulled in the direction of the skew and no longer represents where most of the data sit.

Rather than comparing means, median tests compare **medians**. Because the median is the middle value, it is far less affected by extreme values and skew. Use the tabs below to switch between the mean and median plots and see the difference:

#### Rank Tests

Rather than using the actual values, the data are sorted into order and each observation is assigned a **rank**. The test then examines whether one group tends to rank consistently higher than another. Because the test uses ranks rather than raw values, it is not affected by skew or extreme values, making it a good choice for data that violate the normality assumption.

The table below shows how the ranking process works using parasite counts from a small sample of wood mice:


```{r rank-table, echo=FALSE}
mice_parasites %>%
  select(host_id, sex, parasite_count) %>%
  arrange(parasite_count) %>%
  mutate(rank = rank(parasite_count, ties.method = "average")) %>%
  head(12)
```

When comparing **two groups**, we use the **Wilcoxon rank-sum test** (also called the Mann-Whitney U test), the rank-based equivalent of a two-sample t-test:

```{r, echo=FALSE}

```{r, echo=FALSE}

**Understanding the test statistics:**

- The **Mann-Whitney U test** produces a **W statistic**: if large enough relative to a critical value, it indicates a significant difference between the two groups. 
- The **Kruskal-Wallis test** produces a **chi-squared statistic** (sometimes called H). The larger the value, the more evidence that at least one group has a 
different rank distribution from the others

In both cases, the **p-value** tells us whether the result is statistically significant (p < 0.05).
:::

#### Patterns of Deviation

Rather than looking at the **size** of differences, these methods look at the **direction** of differences. For example, do otters with higher fish availability tend to also have higher spraint counts? We are not asking by how much, just whether the two variables tend to move **together**.

**Non-parametric tests for association:**

When we want to measure the strength of association between two variables, we use a **correlation coefficient**. The most common parametric version is **Pearson's r**, which measures the strength and direction of a linear relationship between two continuous, normally distributed variables and ranges from -1 to 1.

When the data are not normally distributed, or have been collected as ranks, the non-parametric alternatives are **Spearman's** and **Kendall's** correlation coefficients. Both are based on ranking data, yield coefficients comparable to Pearson's r, and a significant result (p < 0.05) indicates a significant association.

**To remind ourselves about the parametric Pearson's r: What does a Pearson's r value of -0.85 tell us?**

`r longmcq(c(
answer = "There is a strong negative association between the two variables — as one increases, the other tends to decrease, and the relationship accounts for a large proportion of the variation.",
"There is a strong positive association between the two variables.",
"There is no meaningful association between the two variables.",
"The relationship between the two variables is non-linear."
))`

```{r, echo=FALSE, warning=FALSE}
otter_data %>%
  select(otter_id, fish_index, spraints) %>%
  mutate(
    rank_fish     = rank(fish_index, ties.method = "average"),
    rank_spraints = rank(spraints,   ties.method = "average")
  ) %>%
  head(10)
```

```{r, echo=FALSE, warning=FALSE, message=FALSE, fig.cap="Figure 6. Ranks of fish availability index plotted against ranks of spraint count.", fig.width=6, fig.height=4}

  mutate(
    rank_fish     = rank(fish_index, ties.method = "average"),
    rank_spraints = rank(spraints,   ties.method = "average")
  ) %>%
  ggplot(aes(x = rank_fish, y = rank_spraints)) +
  geom_point(colour = "#F8766D", size = 2.5) +
  geom_smooth(method = "lm", colour = "black", se = TRUE) +
  labs(x = "Rank of fish availability index",
       y = "Rank of spraint count") +
  theme_minimal(base_size = 13)
```

**Spearman's correlation** is the most commonly used non-parametric correlation in biology. It converts both variables to ranks and tests whether the ranks tend to move together:

```{r, echo=FALSE, warning=FALSE, message=FALSE}
cor.test(otter_data$fish_index, otter_data$spraints,
         method = "spearman")
```

**Kendall's correlation** is an alternative to Spearman's that handles ties more reliably and can be more accurate with smaller sample sizes. It is calculated slightly differently but interpreted in the same way:

```{r, echo=FALSE, warning=FALSE, message=FALSE}
cor.test(otter_data$fish_index, otter_data$spraints,
         method = "kendall")
```

::: {.callout-note}
**Spearman's (ρ) and Kendall's (τ) correlation coefficients** both range 
from -1 to 1, just like Pearson's r:

- **1** — a perfect positive rank association
- **0** — no association between the ranks
- **-1** — a perfect negative rank association

Kendall's τ is typically slightly smaller in value than Spearman's ρ for the same data — this is normal and does not mean one is better than the other. Both lead to the same conclusion about statistical significance. 
In practice, Spearman's is more commonly reported in biology, but either is acceptable.
:::

### The difficulties of non-parametric tests

Non-parametric tests might seem like an easy solution. If the assumptions are violated or transformation does not work, just switch to a non-parametric test right?! However, there are some important things to be aware of before doing this.


When two or more observations share the same value, they are said to be **tied**. Most non-parametric tests are based on ranking, and ties create a problem because two observations cannot occupy the same rank position. R handles this automatically by assigning the **average rank** to tied values, but it is worth knowing this happens.

**If three mice all have a parasite count of 0 and would occupy ranks 1, 2 and 3, what rank does each receive when ties are handled by averaging?**

`r longmcq(c( 
"Each receives rank 1, as they all share the lowest value.",
 answer = "Each receives rank 2. The average of ranks 1, 2 and 3.",
"Each receives rank 3, as there are three of them.",
"The tied observations are removed from the analysis entirely."
))`


---

#### When Should You Use a Non-Parametric Test?

::: {.callout-note}
Use a non-parametric test when:

- The data **are not normally distributed**, and does not meet the assumptions of a parametric test
- The data **cannot be transformed** to meet the normality assumption
- The data were **collected as ranks** or represent an index rather than a true measurement
- The **sample size is very small** and you cannot reliably assess normality

Do **not** use a non-parametric test simply because it is easier or to avoid checking assumptions — always check assumptions first and only switch to a non-parametric test if they cannot be met.
:::
