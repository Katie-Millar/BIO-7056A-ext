6.2 Type I and Type II Errors

These are the two types of errors can occur when we are testing hypotheses, and they are related to the null hypothesis. We were first introduced to the idea of the null hypothesis in Workshop 4. The null hypothesis is a statement that there is between the variables being tested.

6.2.1 Type I Error

If we reject the null hypothesis when it is actually true, we have made a Type I error.

6.2.2 Type II Error

If we fail to reject the null hypothesis when it is actually false, we have made a Type II error. This is also known as a result. We miss a real effect that is actually there.

6.3 Transforming Data

6.3.1 Background to transformations

So far in this module, we have practised a range of statistical tests, including t-tests and ANOVAs. Before running these tests, we always check two key assumptions:

  1. Normality: the data within each group should be approximately normally distributed (checked using the Shapiro-Wilk test and Q-Q plots)

  2. Homogeneity of variance: the variance within each group should be approximately equal (checked using Levene’s test)

When both assumptions are met, we can proceed with a parametric test. When they are not met, we have two options:

  • Use a non-parametric alternative (covered in Workshop 3)
  • Transform the data to see whether the assumptions can be satisfied on a different scale

This section focuses on the second option; data transformation.

Note

What is a transformation?

A transformation applies a mathematical function to every value in a variable. This changes the scale of the data but not the relationships within it — the same otters that had higher tick counts before transformation will still have relatively high counts after transformation. The goal is to make the distribution more symmetrical and closer to normal.

6.3.2 Common Transformations

Transformation R code When to use
Log log(x) or log10(x) Right-skewed data, counts, data spanning several orders of magnitude
Square root sqrt(x) Count data with moderate right skew
Reciprocal 1/x Extreme right skew

The most commonly used transformation in biology is the log transformation, which is particularly useful for count data such as tick counts or parasite counts, as seen in Workshop 2 and this workshop.

What is written in the table may seem a bit daunting at first, but the dropdown below explains each transformation in more detail.

Log Transformation

A log transformation is used when your data are right skewed. As you may remember from the histograms in Workshop 2, right-skewed data have a long tail stretching to the right — most values are clustered at the low end, but a small number of very high values pull the tail outward.

Log transformation works best when the data are:

  • Right skewed: as described above
  • Counts or measurements that cannot be negative — log transformation only works on positive values. Examples from our workshops include:
    • parasite_count from the wood mouse dataset — the number of parasites found on each mouse (discrete)
    • tick_count from the otter dataset — the number of ticks recorded on each otter (discrete)
    • fish_index from the otter dataset — a continuous measure of fish availability (continuous)
  • Spanning a wide range of values — for example, values ranging from 1 to 1,000, where the high values are distorting the distribution

Square Root Transformation

A square root transformation is a milder version of the log transformation. It is useful when the data are moderately right-skewed but the skew is not as extreme.

If the log transformation overcorrects and makes the data left-skewed, try the square root transformation instead.

It works best for:

  • Count data with moderate skew
  • Data where zeros are present

Reciprocal Transformation

The reciprocal transformation (1/x) is the strongest of the three and is used only when the data are extremely right skewed — for example, reaction times or waiting times, where a few very large values dominate the distribution.

Warning

The reciprocal transformation reverses the order of the data — a large value becomes a small value and vice versa. This means results must be interpreted carefully. It also cannot be applied when any values are zero.

Warning

Important: log(0) is undefined in mathematics. If your data contain zeros (which count data often does), always use log(x + 1) instead. This shifts all values up by 1 before taking the log, avoiding the problem.

6.3.3 The Workflow

The key principle is to check, transform, then check again:

  • Check normality of the original data (Shapiro-Wilk)
  • If assumptions are violated, apply a transformation
  • Check normality of the transformed data (Shapiro-Wilk)
  • If assumptions are now met, proceed with parametric test on transformed data
  • If assumptions are still violated, consider a non-parametric test instead

We will first go through examples of how to do this together, you will then be tasked with applying the workflow to a new dataset in the exercise, and writing the code yourselves.

After transformation, we check the Shapiro-Wilk test again:

  • If p > 0.05: the transformed data are approximately normal; proceed with a parametric test using log_tick_count

In our case, the Shapiro-Wilk test returns p = 0.112 after log transformation, the tick count data are now approximately normally distributed and we can proceed with a parametric test.

6.5 Non-Parametric Alternatives

When transformation does not work, we can use a non-parametric test instead. Non-parametric tests do not assume that the data are normally distributed, and they make no assumptions about the distribution of the data at all. They do not work by predicting the likely values of population parameters from sample statistics.

If you remember from Workshop 3, we introduced the concept of non-parametric equivalents. The table below serves as a reminder:

6.5.1 Median Tests

Most parametric tests compare means. For example, a t-test compares the mean of one group to the mean of another, an ANOVA compares the means of multiple groups, and linear regression asks whether the mean of one variable changes in relation to another. However, when the data are skewed, the mean is pulled in the direction of the skew and no longer represents where most of the data sit.

Rather than comparing means, median tests compare medians. Because the median is the middle value, it is far less affected by extreme values and skew. Use the tabs below to switch between the mean and median plots and see the difference:

6.5.2 Rank Tests

Rather than using the actual values, the data are sorted into order and each observation is assigned a rank. The test then examines whether one group tends to rank consistently higher than another. Because the test uses ranks rather than raw values, it is not affected by skew or extreme values, making it a good choice for data that violate the normality assumption.

Note

Understanding the test statistics:

  • The Wilcoxon rank-sum test (also called the Mann-Whitney U test) produces a W statistic: if large enough relative to a critical value, it indicates a significant difference between the two groups.
  • The Kruskal-Wallis test produces a chi-squared statistic (sometimes called H). The larger the value, the more evidence that at least one group has a different rank distribution from the others

In both cases, the p-value tells us whether the result is statistically significant (p < 0.05).

6.5.3 Patterns of Deviation

Rather than looking at the size of differences, these methods look at the direction of differences. For example, do otters with higher fish availability tend to also have higher spraint counts? We are not asking by how much, just whether the two variables tend to move together.

6.5.3.1 Non-parametric tests for association

When we want to measure the strength of association between two variables, we use a correlation coefficient. The most common parametric version is Pearson’s r, which measures the strength and direction of a linear relationship between two continuous, normally distributed variables and ranges from -1 to 1.

When the data are not normally distributed, or have been collected as ranks, the non-parametric alternatives are Spearman’s and Kendall’s correlation coefficients. Both are based on ranking data, yield coefficients comparable to Pearson’s r, and a significant result (p < 0.05) indicates a significant association.

6.5.3.2 The difficulties of non-parametric tests

Non-parametric tests might seem like an easy solution. If the assumptions are violated or transformation does not work, just switch to a non-parametric test right?! However, there are some important things to be aware of before doing this.

When two or more observations share the same value, they are said to be tied. Most non-parametric tests are based on ranking, and ties create a problem because two observations cannot occupy the same rank position. R handles this automatically by assigning the average rank to tied values, but it is worth knowing this happens.

6.6 When Should You Use a Non-Parametric Test?

Note

Use a non-parametric test when:

  • The data are not normally distributed, and does not meet the assumptions of a parametric test
  • The data cannot be transformed to meet the normality assumption
  • The data were collected as ranks or represent an index rather than a true measurement
  • The sample size is very small and you cannot reliably assess normality

Do not use a non-parametric test simply because it is easier or to avoid checking assumptions — always check assumptions first and only switch to a non-parametric test if they cannot be met.

## Transforming Data

### Background to transformations 

So far in this module, we have practised a range of statistical tests, including **t-tests** and **ANOVAs**. Before running these tests, we always check two key assumptions:

1. **Normality**: the data within each group should be approximately normally distributed (checked using the Shapiro-Wilk test and Q-Q plots)

2. **Homogeneity of variance**: the variance within each group should be approximately equal (checked using Levene's test)

When both assumptions are met, we can proceed with a **parametric test**. When they are not met, we have two options:

- Use a **non-parametric alternative** (covered in [Workshop 3](03-ext.qmd))
- **Transform the data** to see whether the assumptions can be satisfied on a different scale

This section focuses on the second option; data transformation.

::: {.callout-note}
**What is a transformation?**

A transformation applies a mathematical function to every value in a variable. This changes the **scale** of the data but not the relationships within it — the same otters that had higher tick counts before transformation will still have relatively high counts after transformation. The goal is to make the distribution more symmetrical and closer to normal.
:::

---

### Common Transformations

| Transformation | R code | When to use |
|---|---|---|
| **Log** | `log(x)` or `log10(x)` | Right-skewed data, counts, data spanning several orders of magnitude |
| **Square root** | `sqrt(x)` | Count data with moderate right skew |
| **Reciprocal** | `1/x` | Extreme right skew |

The most commonly used transformation in biology is the **log transformation**, which is particularly useful for count data such as tick counts or parasite counts, as seen in [Workshop 2](02-ext.qmd) and this workshop.

What is written in the table may seem a bit daunting at first, but the dropdown below explains each transformation in more detail.

`r hide("Common transformations in more detail")`

**Log Transformation**

A log transformation is used when your data are **right skewed**. As you may remember from the histograms in [Workshop 2](02-ext.qmd), right-skewed data have a long tail stretching to the right — most values are clustered at the low end, but a small number of very high values pull the tail outward.

Log transformation works best when the data are:

- **Right skewed**: as described above
- **Counts or measurements that cannot be negative** — log transformation only works on positive values. Examples from our workshops include:
    - `parasite_count` from the wood mouse dataset — the number of parasites found on each mouse (discrete)
    - `tick_count` from the otter dataset — the number of ticks recorded on each otter (discrete)
    - `fish_index` from the otter dataset — a continuous measure of fish availability (continuous)
- **Spanning a wide range of values** — for example, values ranging from 1 to 1,000, where the high values are distorting the distribution

---

**Square Root Transformation**

A square root transformation is a **milder** version of the log transformation. It is useful when the data are moderately right-skewed but the skew is not as extreme.

> *If the log transformation overcorrects and makes the data left-skewed, try the square root transformation instead.*

It works best for:

- **Count data** with moderate skew
- Data where zeros are present

---

**Reciprocal Transformation**

The reciprocal transformation (`1/x`) is the **strongest** of the three and is used only when the data are **extremely right skewed** — for example, reaction times or waiting times, where a few very large values dominate the distribution.

::: {.callout-warning}
The reciprocal transformation **reverses the order** of the data — a large value becomes a small value and vice versa. This means results must be interpreted carefully. It also cannot be applied when any values are zero.
:::

`r unhide()`

::: {.callout-warning}
**Important:** `log(0)` is undefined in mathematics. If your data contain zeros (which count data often does), always use `log(x + 1)` instead. This shifts all values up by 1 before taking the log, avoiding the problem.
:::

## Non-Parametric Alternatives

When transformation does not work, we can use a **non-parametric test** instead. Non-parametric tests do not assume that the data are normally distributed, and they make no assumptions about the distribution of the data at all. They do not 
work by predicting the likely values of population parameters from sample statistics.

If you remember from [Workshop 3](03-ext.qmd), we introduced the concept of non-parametric equivalents. The table below serves as a reminder:

| Parametric test | Non-parametric equivalent |
|---|---|
| One-sample t-test | Wilcoxon signed-rank test |
| Two-sample t-test (unpaired) | Mann-Whitney U / Wilcoxon rank-sum test |
| Two-sample t-test (paired) | Wilcoxon signed-rank test |
| Pearson correlation | Spearman correlation |
| One-way ANOVA | Kruskal-Wallis test |
| Randomised block two-way ANOVA | Friedman's test |

Rather than comparing means, median tests compare **medians**. Because the median is the middle value, it is far less affected by extreme values and skew. Use the tabs below to switch between the mean and median plots and see the difference:

Rather than using the actual values, the data are sorted into order and each observation is assigned a **rank**. The test then examines whether one group tends to rank consistently higher than another. Because the test uses ranks rather than raw values, it is not affected by skew or extreme values, making it a good choice for data that violate the normality assumption.

**Understanding the test statistics:**

- The **Wilcoxon rank-sum test** (also called the Mann-Whitney U test) produces a **W statistic**: if large enough relative to a critical value, it indicates a significant difference between the two groups. 
- The **Kruskal-Wallis test** produces a **chi-squared statistic** (sometimes called H). The larger the value, the more evidence that at least one group has a 
different rank distribution from the others

In both cases, the **p-value** tells us whether the result is statistically significant (p < 0.05).
:::

### Patterns of Deviation

Rather than looking at the **size** of differences, these methods look at the **direction** of differences. For example, do otters with higher fish availability tend to also have higher spraint counts? We are not asking by how much, just whether the two variables tend to move **together**.                  
                                         
                   
             
#### Non-parametric tests for association            

When we want to measure the strength of association between two variables, we use a **correlation coefficient**. The most common parametric version is **Pearson's r**, which measures the strength and direction of a linear relationship between two continuous, normally distributed variables and ranges from -1 to 1.

When the data are not normally distributed, or have been collected as ranks, the non-parametric alternatives are **Spearman's** and **Kendall's** correlation coefficients. Both are based on ranking data, yield coefficients comparable to Pearson's r, and a significant result (p < 0.05) indicates a significant association.

"There is no meaningful association between the two variables, neither is linear.",
"The relationship between the two variables is non-linear, and the correlation coefficient does not capture this relationship."
))`


#### The difficulties of non-parametric tests

Non-parametric tests might seem like an easy solution. If the assumptions are violated or transformation does not work, just switch to a non-parametric test right?! However, there are some important things to be aware of before doing this.


When two or more observations share the same value, they are said to be **tied**. Most non-parametric tests are based on ranking, and ties create a problem because two observations cannot occupy the same rank position. R handles this automatically by assigning the **average rank** to tied values, but it is worth knowing this happens.

#### Spearman's and Kendall's Correlation 
So far in this section we have looked at tests for **differences between groups**: the Wilcoxon rank-sum test and the Kruskal-Wallis test. But what if we want to test for an **association between two variables**, just as we used linear regression in [Workshop 5](05-testing-and-measuring-relationships.qmd). 

Both work by examining whether the **ranks** of the two variables tend to move together, rather than the raw values.

Now we have seen how the ranks of the two variables relate to each other, we can formally test this using a non-parametric correlation. **Spearman's correlation** is the most commonly used non-parametric correlation in biology. It converts both variables to ranks and tests whether the ranks tend to move together:

```{r}

         method = "spearman")
```

**Kendall's correlation** is an alternative to Spearman's that handles ties more reliably and can be more accurate with smaller sample sizes. It is calculated slightly differently but interpreted in the same way:

```{r, echo=FALSE, warning=FALSE, message=FALSE}

         method = "kendall")
```

- **0**: no association between the ranks
- **-1**: a perfect negative rank association

## When Should You Use a Non-Parametric Test?

::: {.callout-note}
Use a non-parametric test when:

- The data **are not normally distributed**, and does not meet the assumptions of a parametric test
- The data **cannot be transformed** to meet the normality assumption
- The data were **collected as ranks** or represent an index rather than a true measurement
- The **sample size is very small** and you cannot reliably assess normality

Do **not** use a non-parametric test simply because it is easier or to avoid checking assumptions — always check assumptions first and only switch to a non-parametric test if they cannot be met.
:::
