A LOT of functions have been learnt in this module, and it can be hard to remember them all. This glossary is intended to be a reference for the functions that have been used in this module. It is not an exhaustive list of all functions in R, but it does cover the most commonly used functions in this module.

7.1 Loading Packages

Function Package What it does Example
library() Base R Loads an installed package into your session library(tidyverse)
install.packages() Base R Installs a package from CRAN install.packages("tidyverse")
Note

In Posit Cloud, which we regularly use in this module, the packages will need to be reinstalled each time you start a new session. If you are using a downloaded application like RStudio Desktop, or Positron, you only need to install packages once. You will still need to load the packages each time you start a new session.

7.5 Summary Statistics

Function Package What it does Example
mean() Base R Calculates the mean mean(weight_g)
median() Base R Calculates the median median(weight_g)
sd() Base R Calculates the standard deviation sd(weight_g)
max() Base R Returns the maximum value max(parasite_count)
min() Base R Returns the minimum value min(parasite_count)
range() Base R Returns the minimum and maximum values range(parasite_count)
diff() Base R Calculates the difference between values diff(range(parasite_count))
n() tidyverse Counts the number of observations in a group summarise(n = n())
Mode() DescTools Calculates the mode Mode(parasite_count)
table() Base R Creates a frequency table table(parasite_count)
cor.test() Base R Calculates Pearson or Spearman correlation cor.test(x, y, method = "pearson")

7.6 Statistical Tests

Function Package What it does Example
t.test() Base R Runs a one-sample or two-sample t-test t.test(fly_count ~ tree_type, data = medfly_orchard)
shapiro.test() Base R Shapiro-Wilk test for normality shapiro.test(spraints)
leveneTest() car Levene’s test for equal variances leveneTest(richness ~ treatment, data = grassland)
aov() Base R Fits an ANOVA model aov(richness ~ treatment, data = grassland)
TukeyHSD() Base R Tukey post-hoc test after ANOVA TukeyHSD(anova_result)
lm() Base R Fits a linear regression model lm(spraints ~ fish_index, data = otter_data)
